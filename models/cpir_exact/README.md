# CPIR有限精确商回归模型

本目录实现专题09E与附录C登记的“CPIR-X1—X8”，并提供一个有限精确正例。模型只使用有限集合、确定映射和有限Markov核，复用偏序商、强可块化、目标可测性和实现不变性的标准判据。

| 编号 | 检查的错误推论 |
|---|---|
| X1 | 任意分区自动产生合法偏序商 |
| X2 | SCC修复后原证书继续有效 |
| X3 | 任意分区自动产生Markov宏观核 |
| X4 | 宏观操作天然具有唯一微观实现效应 |
| X5 | 动力闭合自动保证任务充分性 |
| X6 | 单步拟合自动保证多步无记忆 |
| X7 | 动力商自动保存持存身份 |
| X8 | 描述压缩自动产生新能力 |

正例同时检查强可块化、目标可测、持存可测和内部置换实现不变性。通过这些测试只解除CPIR-T1/C1的机器回归锁；定理身份仍需要正文证明、来源映射和人工审核共同确认。
