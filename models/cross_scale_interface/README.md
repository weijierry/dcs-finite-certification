# 有限跨尺度因果接口原型

本模型使用有限受控 Markov 链和全部 15 种存活态分区，检验选择性因果压缩、动力闭合、干预交换、有限记忆、条件持存与接口成本是否在同一粗粒化上共同成立。

复用的成熟构件：

1. 有限受控转移核和矩阵幂；
2. Kemeny--Snell/Buchholz block-rate lumpability；
3. 两步宏观核误差作为有限记忆诊断；
4. 确定性微观干预与宏观商映射的交换误差；
5. Jensen--Shannon未来响应距离；
6. 对称Gram谱的数值秩和参与率有效秩；
7. 多目标Pareto支配。

选择采用两阶段规则：先要求非平凡类间响应、真实压缩以及响应、闭合、记忆、干预和持存误差通过硬门，再在合格分区中比较Pareto。原始Pareto前沿仍完整保存，用来展示“一块塌缩”可能因接口成本最低而留在前沿，因此Pareto成员资格本身不构成有效层认证。

登记模型有微观态 `A0,A1,B0,B1,D`，其中 `D` 为吸收失败态。三个动作是 `baseline`、`protect_a` 和 `protect_b`；未来响应在1、2、3步上按 `A/B/D` 结果统计。注册分区为 `{A0,A1}|{B0,B1}|{D}`。

运行：

```powershell
python run_model.py
```

输出 `results.json` 同时保存对称模型和块内异质模型。模型只建立有限状态反例与认证基线；跨模型普遍性、连续流形、RG固定点和生命/智能解释仍由后续桥接承担。
