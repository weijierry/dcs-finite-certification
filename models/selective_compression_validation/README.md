# 选择性因果压缩跨模型验证

本目录包含两个有限、完全可观测、可重复的模型族：

1. `SCC-F1-metastable`：六状态双亚稳盆地链，复用有限 Markov 谱分析和精确聚合；
2. `SCC-RG-F0-hierarchical`：八状态层级比特链，复用独立 Markov 过程的乘积结构与精确粗粒化。
3. `SCC-F2-circulating-nonreversible`：八状态双盆地定向环流链，用稳态概率流确认非可逆性，并扫描块内异质逃逸造成的平台崩溃。

运行：

```powershell
python run_model.py
```

模型用于验证 09D 的合同逻辑。它们说明精确对齐和因果平台可以在受控族中出现，也提供破坏对称性、乘积结构与可逆性后的失效出口；不代表一般复杂系统或真实物理系统。
